# Write evidence another operator can use

Give each Markdown note a title, type and date. A fact cites a specific source. An inference names a derivation and links to at least one fact. An assumption states its rationale and remains open until measured. Add links with `[[folder/note]]`. Use a folder when two files share a name.

Claim notes add a unique ID, licensed figures and a review date. Signing a claim records its digest. Editing its source requires another review. For public statements, keep the scope of the sentence as narrow as the underlying observation. A measured saving on one dispatch exercise does not establish what an average customer will save.

Run `mktgkit brain check` in a workspace to find missing sources, broken links, duplicate claim IDs and overdue notes. Run `mktgkit brain graph --format json` to inspect the graph or use the default Mermaid output in a document. [Worked claim](../examples/wrenfield/brain/claims/C-001-route-building-time.md)
