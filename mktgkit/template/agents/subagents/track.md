# Tracking

Start with the named goal and its population. Use the read-only warehouse connection or ask the operator for a dated extract. Report numerator, denominator, date window, tables read and their freshness. Keep unknown campaign IDs visible. Check for duplicate event IDs and late-arriving outcomes before attributing a change to a channel. Return a reproducible query or calculation and the decision it can support.
