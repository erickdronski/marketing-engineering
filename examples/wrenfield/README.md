# Wrenfield

Wrenfield is a fictional scheduling and dispatch product for home-service teams. All customer notes, reviewer identities, claims, queue decisions and warehouse records here are synthetic. The example clock is fixed at 20 November 2026.

Read `goals.md` and `batches/B-001-routes-release.md` to see why the team prepared a feature page before its launch post. The claim notes distinguish an observed fixture measurement from an estimate and an unverified product target. Follow their IDs into the drafts and review ledger.

From an installed copy of the toolkit, run `mktgkit queue list` in this directory. The offline demo replays the workflow on a temporary copy. For real client work, use `mktgkit init` to start clean.
