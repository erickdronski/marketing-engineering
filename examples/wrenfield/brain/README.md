# Workspace knowledge

Give each note a unique filename. Use `offers/` for product promises, `customers/` for observed needs, `brand/` for language, `claims/` for figures to review, `research/` for dated outside evidence, `results/` for outcomes, `edits/` for reviewer feedback and `skills/` for repeatable methods.

A fact needs a dated, identifiable source. An inference needs a derivation and a link to a fact. An assumption needs a rationale and an owner who can test it. Put links in the note body using doubled square brackets around the target filename stem. A claim includes a unique ID and the exact figures it licenses. The reviewer checks the source before signing.

Store aggregate or redacted evidence here. Keep customer contact details, secrets and unredacted CRM exports inside approved client systems. Recheck time-sensitive notes before using them for copy.
