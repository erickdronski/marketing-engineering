# Changelog

## 0.1.1

The warehouse now reconciles each snapshot against the row count in its newest source load. A partial export cannot replace a valid database. Workspace checks flag pending CSV mismatches, and queries and MCP tools also catch mismatches in databases built by earlier versions. Historical loads and correctly recorded empty exports remain supported.

## 0.1.0

Initial toolkit and consultant field guide. Includes a blank client workspace, the fictional Wrenfield engagement, versioned draft reviews, claim sign-offs, action permissions, a read-only SQLite warehouse and MCP server, and an offline lead-handoff recipe.
